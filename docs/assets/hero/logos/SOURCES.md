# Logo sources

Collected 2026-11-22 for the ctxtree README hero (docs/assets/hero.gif). Third party marks are used only to identify the tools ctxtree works with (nominative use). They are shown unmodified on a neutral white tile next to the tool name. Do not recolor, distort, animate the shape of, or combine these marks with other marks, and do not imply endorsement. Check each brand rule before release.
